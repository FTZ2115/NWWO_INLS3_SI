# Code of Conduct - Zasadu postępowania

1. Cel kodeksu:
-Głównym celem niniejszego kodeksu jest stworzenie otwartego, bezpiecznego i przyjaznego środowiska dla wszystkich osób biorących udział w projekcie.

2.  Zasady współpracy:
-Szacunek i kultura osobista: Traktuj innych tak, jak sam(a) chcesz być traktowany(a). Używaj włączającego, uprzejmego języka.
-Wsparcie i dzielenie się wiedzą: Pamiętaj, że projekt ma charakter edukacyjny. Pomagaj mniej doświadczonym członkom zespołu i cierpliwie odpowiadaj na pytania.
-Konstruktywne podejście: Skupiaj się na rozwiązywaniu problemów, a nie na szukaniu winnych.
-Otwartość na informację zwrotną: Przyjmuj uwagi i sugestie do własnego kodu z otwartą głową.

3. Niedopuszczalne zachowania:
-Stosowania mowy nienawiści, dyskryminacji, obraźliwych komentarzy czy osobistych ataków.
-Trollowania, hejtu oraz celowego wprowadzania zamieszania lub wywoływania konfliktów.
-Niewłaściwego lub niechcianego kontaktu (w tym nękania w wiadomościach prywatnych lub publicznych).

4. Code Review:
-Oceniaj kod, nie osobę: Sugestie powinny dotyczyć rozwiązań technicznych, czytelności i poprawności kodu, a nie umiejętności autora.
-Uzasadniaj swoje uwagi: Zamiast pisać "to jest źle", wyjaśnij dlaczego warto zastosować inne rozwiązanie i zaproponuj alternatywę.

5.  Zgłaszanie naruszeń:
-Zgłoś zaistniałą sytuację bezpośrednio do opiekuna/maintainera projektu (np. poprzez kontakt podany w profilu GitHub lub prywatną wiadomość).
-Zgłoszenia będą traktowane poufnie, a każda sprawa zostanie przeanalizowana indywidualnie.
6.  Konsekwencje naruszeń:
-Prywatne upomnienie: Wyjaśnienie niewłaściwego zachowania i prośba o zmianę postawy.
-Odrzucenie zgłoszeń (PR / Issues): Zamknięcie zgłoszeń tworzonych w sposób złośliwy lub naruszający zasady.
-Czasowe lub trwałe zablokowanie: Usunięcie z listy współtwórców oraz zablokowanie dostępu do repozytorium projektu w przypadku uporczywego łamania regulaminu.

**Współpraca, wzajemny szacunek i odpowiedzialność za własną pracę są podstawą rozwoju tego projektu.**
